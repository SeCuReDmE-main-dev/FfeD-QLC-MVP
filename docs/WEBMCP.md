# FfeD-QLC WebMCP source contract

`GET /api/v1/webmcp/manifest` publishes ten product tools mapped to existing
service handlers plus the two shared companion tools. Discovery occurs before
login; invocation fails closed until a trusted Gateway `session.v2` authorizer
is installed. No descriptor starts training, provisions infrastructure, opens a
browser, invokes a shell, or exposes `.env`, plaintext, private keys, raw T/I/F,
or raw media. Unknown capabilities return `TOOL_UNAVAILABLE`.

Theme provenance is the product-specific Stitch handoff
`securedme-site/assets/landing/secureme.ca-product/education/FfeD-QLC-MVP/desing/stitch_ffed_qlc_design_system_landing_page/stitch_ffed_qlc_design_system_landing_page/desing.md`
with `sourceStatus: verified-product-stitch`.
The accessible fallback uses high-contrast system fonts, visible focus, and
textual gate states.
