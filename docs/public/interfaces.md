# Interfaces

- **Vite student/professor workbench:** preserves separate learning and review authority.
- **ffed-qlc command line:** use only through the documented repository route.
- **FastAPI `/api/v1`:** exposes health, capabilities, contracts and bounded synthetic demonstrations; persistent operations require the reviewed Gateway and identity adapter.
- **FQLC2 local CLI:** owns real key generation, pack, inspect, verify, unpack and full recipient rotation.
- **Vigil report:** is generated by `ffed-deterministic-engine`, schema-validates evidence and limitations, and never assigns a final grade or security certification.
- **Native handoff:** calls the existing local Pivot runtime and requires its receipt; Passenger returns `NATIVE_RUNTIME_UNAVAILABLE`.

## Interface contract

Inputs must be explicit, outputs must be inspectable, errors must be returned as errors, and consequential external actions require human approval.

## Compatibility

Treat undocumented endpoints, commands, and browser controls as unsupported. Confirm the current repository version before integrating another system.
