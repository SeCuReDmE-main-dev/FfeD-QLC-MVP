# Student Path

Students enter through a Gateway-issued pseudonymous role. Prior suite metrics are useful but optional. When no prior evidence exists, Vigil starts at `lab-01` and records that the absence of history is not a failure.

## Nine laboratories

1. Identify the boundary between scrypt, AEAD and geometry.
2. Inspect an FQLC1 public header.
3. Classify useful and avoidable metadata.
4. Compare source bytes with a geometric permutation.
5. Verify exact Apollonian reflections, cycles and symmetry collisions.
6. Run a bounded red-team action against a synthetic fixture.
7. Apply and document a defensive correction.
8. Request a minimal metric from another Education tool through Vigil and the Gateway.
9. Assemble a capstone orb and portfolio evidence bundle.

Every run records the action, fixture, proof, limitation and Tenebris budgets. A successful action produces evidence, not a grade. Vigil organizes the evidence; a professor retains the final decision.
