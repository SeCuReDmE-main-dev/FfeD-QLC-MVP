# Professor Path

The professor uses a Gateway `teacher` session and a dedicated review surface.

## Responsibilities

- Select or reduce Tenebris budgets.
- Confirm that fixtures are synthetic and appropriate for the course level.
- Review deterministic evidence before the Vigil explanation.
- Compare each claim with its mechanism and stated limitation.
- Accept, suspend, reject or request revision.
- Decide whether a portfolio export is suitable for publication.

Vigil can recommend a route and request bounded handoffs from remote mascots. It cannot assign a final grade, certify security, publish evidence or override the professor.

The learning route covers a Secondary 5 bridge, applied college cryptography and university capstone evidence governance.

## Reduce a project budget

1. Open a Gateway-backed teacher session.
2. Select the supervised student project.
3. Reduce mission retries or geometry trace steps in the Tenebris panel.
4. Apply the profile and confirm the enforced state.

The API refuses unknown fields, zero or negative values, and every value above the alpha maximum. A student session cannot change a budget profile.
